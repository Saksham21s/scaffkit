# Renaming Guide — Prism → Docify

> **Complete cross-cutting rename from "Prism" to "Docify".**

---

## Why the Rename?

| Aspect | Prism | Docify |
|--------|-------|--------|
| **Meaning** | Light refraction | Document + Certify (generate docs + scaffold) |
| **npm availability** | Taken | Available ✅ |
| **Memorability** | Generic, conflicts | Unique, action-oriented |
| **Domain** | prism.dev → likely taken | docify.dev → available ✅ |
| **CLI mental model** | "prism init" — neutral | "docify init" — implies documentation + creation |

---

## Search & Replace Map

### 1. Package-Level Replacements

| File | Search | Replace | Notes |
|------|--------|---------|-------|
| `package.json` | `"name": "prism"` | `"name": "docify"` | npm package name |
| `package.json` | `"prism"` | `"docify"` | In scripts, bin, etc. |
| `package-lock.json` | `"prism"` | `"docify"` | Will be auto-regenerated |
| `README.md` | `# Prism` | `# Docify` | Title |
| `README.md` | `prism init` | `docify init` | CLI commands |
| `README.md` | `npx prism` | `npx docify` | Usage examples |

### 2. Source Code Replacements

| File Pattern | Search | Replace | Notes |
|-------------|--------|---------|-------|
| `src/**/*.ts` | `PrismConfig` | `DocifyConfig` | Config interface |
| `src/**/*.ts` | `class PrismError` | `class DocifyError` | Error class |
| `src/**/*.ts` | `PrismError` | `DocifyError` | All references |
| `src/**/*.ts` | `enum ErrorCode` | keep `ErrorCode` | Enum name stays (generic) |
| `src/**/*.ts` | `PRISM_INJECT` | `DOCIFY_INJECT` | Anchor markers |
| `src/**/*.ts` | `PRISM-DYNAMIC` | `DOCIFY-DYNAMIC` | Dynamic injection markers |
| `src/**/*.ts` | `.prism-temp-build` | `.docify-temp-build` | Temp directory |
| `src/**/*.ts` | `prism.config.json` | `docify.config.json` | Config file name |
| `src/**/*.ts` | `prism-` prefix | `docify-` prefix | CSS vars, storage keys |

### 3. Template File Replacements

| File Pattern | Search | Replace | Notes |
|-------------|--------|---------|-------|
| `src/templates/**/*.ejs` | `Prism` | `Docify` | In generated comments |
| `src/templates/**/*.ejs` | `prism` | `docify` | In generated code |
| `src/templates/**/*.ejs` | `PRISM_` | `DOCIFY_` | In env vars, constants |
| `src/templates/core/package.json.ejs` | `"prism"` | `"docify"` | Metadata |
| `src/templates/state/providers.tsx.ejs` | `PrismProvider` | `DocifyProvider` | Provider name |

### 4. Documentation Replacements

| File | Search | Replace | Notes |
|------|--------|---------|-------|
| `docify-docs/**/*.md` | `# Prism` | `# Docify` | All headings |
| `docify-docs/**/*.md` | `prism init` | `docify init` | CLI references |
| `docify-docs/**/*.md` | `npx prism` | `npx docify` | Usage |
| `docify-docs/**/*.md` | `Prism` → `Docify` | (with exceptions) | Keep "Prism" in historical context |

### 5. Config File Content

| Context | Search | Replace | Notes |
|---------|--------|---------|-------|
| Generated `docify.config.json` | `"prismVersion"` | `"docifyVersion"` | Config schema |
| Generated `docify.config.json` | `"prism"` in metadata | `"docify"` | All metadata fields |
| Storage keys in browser | `prism-theme-*` | `docify-theme-*` | localStorage keys |

### 6. Environment Variables

| Variable | Rename to |
|----------|-----------|
| `PRISM_API_BASE_URL` | `DOCIFY_API_BASE_URL` |
| `PRISM_APP_TITLE` | `DOCIFY_APP_TITLE` |
| `VITE_PRISM_*` | `VITE_DOCIFY_*` |

### 7. Generated File Content

| Pattern | Search | Replace |
|---------|--------|---------|
| Generated README header | `# Project Name` | Keep as project name from config |
| Generated file headers | `Generated by Prism` | `Generated by Docify v1.0.0` |
| Generated comments | `// Prism auto-generated` | `// Docify auto-generated` |
| Package metadata | `"generatedBy": "prism"` | `"generatedBy": "docify"` |

### 8. CSS Class Names & Selectors

| Pattern | Search | Replace |
|---------|--------|---------|
| `.prism-*` prefixes | `.prism-` | `.docify-` |
| `data-prism-*` attributes | `data-prism-` | `data-docify-` |
| CSS variable `--prism-*` | `--prism-` | `--docify-` |

### 9. Test & Fixture Files

| File Pattern | Search | Replace |
|-------------|--------|---------|
| `test/fixtures/*.ts` | `PrismConfig` | `DocifyConfig` |
| `test/fixtures/*.ts` | `prism.config.json` | `docify.config.json` |
| `test/**/*.test.ts` | `Prism` in test names | `Docify` |

### 10. Binary & Entry Points

| File | Search | Replace |
|------|--------|---------|
| `package.json` `"bin"` | `"prism": "./dist/index.js"` | `"docify": "./dist/index.js"` |
| `src/cli/index.ts` | `program.name("prism")` | `program.name("docify")` |
| `src/cli/index.ts` | `.description("Prism CLI")` | `.description("Docify CLI")` |

---

## Files That Should NOT Be Renamed

| File | Reason |
|------|--------|
| `node_modules/` | External dependencies |
| `docify-docs/` | This IS the new name — no change needed |
| `package-lock.json` | Will be regenerated |
| `dist/` | Build output, regenerated |
| `LICENSE` | License text, no brand references |

## Rename Execution Script

```bash
#!/bin/bash
# Execute from project root

echo "=== Renaming Prism → Docify ==="

# 1. Source files (TS/TSX)
echo "[1/6] Renaming source files..."
find ./src -type f \( -name "*.ts" -o -name "*.tsx" \) -exec sed -i \
  -e 's/PrismConfig/DocifyConfig/g' \
  -e 's/PrismError/DocifyError/g' \
  -e 's/prism\.config\.json/docify\.config\.json/g' \
  -e 's/PRISM_INJECT/DOCIFY_INJECT/g' \
  -e 's/PRISM-DYNAMIC/DOCIFY-DYNAMIC/g' \
  -e 's/\.prism-temp-build/\.docify-temp-build/g' \
  {} +

# 2. Template files (EJS)
echo "[2/6] Renaming template files..."
find ./src/templates -type f -name "*.ejs" -exec sed -i \
  -e 's/Prism/Docify/g' \
  -e 's/prism-/docify-/g' \
  -e 's/PRISM_/DOCIFY_/g' \
  {} +

# 3. Test files
echo "[3/6] Renaming test files..."
find ./test -type f -name "*.ts" -exec sed -i \
  -e 's/PrismConfig/DocifyConfig/g' \
  -e 's/prism\.config/docify\.config/g' \
  -e 's/Prism/Docify/g' \
  {} +

# 4. Documentation
echo "[4/6] Renaming documentation..."
find ./docs -type f -name "*.md" -exec sed -i \
  -e 's/# Prism/# Docify/g' \
  -e 's/prism init/docify init/g' \
  -e 's/npx prism/npx docify/g' \
  {} +

# 5. CLI entry
echo "[5/6] Updating CLI entry..."
sed -i \
  -e 's/\.name("prism")/.name("docify")/g' \
  -e 's/"Prism CLI"/"Docify CLI"/g' \
  ./src/cli/index.ts

# 6. Package manifest
echo "[6/6] Updating package.json..."
sed -i \
  -e 's/"name": "prism"/"name": "docify"/g' \
  -e 's/"prism"/"docify"/g' \
  ./package.json

echo "=== Rename complete! ==="
echo "Run 'npm run build' to verify."
```

## Rename Verification Checklist

- [ ] `npm run build` succeeds
- [ ] `node dist/index.js --version` shows "docify"
- [ ] `node dist/index.js init --yes --output ./test` generates project
- [ ] Generated project's `package.json` has correct metadata
- [ ] No references to "Prism" remain in `src/`
- [ ] No references to "Prism" remain in generated output
- [ ] Anchor comments use `DOCIFY_INJECT` prefix
- [ ] Config file is named `docify.config.json`
- [ ] Temp dir is `.docify-temp-build`
- [ ] Tests pass: `npm test`
